# Computer Networks – Physical Networking Lab

## 📌 Lab Overview

This lab was a **physical Computer Networks laboratory activity** focused on understanding how network devices are connected using **Ethernet cables**.

The purpose of the lab was to gain hands-on experience with physical network connections, Ethernet cables, RJ-45 connectors, and basic network connectivity.

## 🎯 Objectives

* Understand the basics of physical computer networking.
* Identify and use Ethernet network cables.
* Learn how network devices are physically interconnected.
* Understand the role of Ethernet ports in networking.
* Practice making proper cable connections between network devices.
* Observe the physical requirements for establishing network connectivity.

## 🔌 Practical Work

During the lab, we performed physical Ethernet connections between networking devices.

The practical activities included:

1. Identifying Ethernet ports on computers and networking devices.
2. Connecting computers to a network switch using Ethernet cables.
3. Checking the physical connection between devices.
4. Observing the link/activity indicators on network ports.
5. Understanding how Ethernet cables provide the physical connection required for communication.
6. Troubleshooting basic physical connectivity issues such as loose or incorrect cable connections.

## 🌐 Key Concepts Learned

### Ethernet Cable

An Ethernet cable is a network cable used to connect devices and transfer data over a wired network.

### RJ-45 Connector

RJ-45 is the commonly used connector for Ethernet networking cables.

### Network Switch

A switch connects multiple devices within a local area network (LAN) and forwards data between connected devices.

### Physical Layer

The physical layer is responsible for transmitting raw bits through physical media such as Ethernet cables.

## 🧪 Lab Outcome

After completing this practical, I gained hands-on understanding of how network devices are physically connected using Ethernet cables and how proper physical connections are necessary for network communication.

## 📚 Conclusion

This lab provided practical exposure to the **physical aspects of computer networking**. It helped in understanding Ethernet connections, network ports, cables, and the basic physical infrastructure required to establish a LAN.
